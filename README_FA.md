# پروژه Reminder برای ساخت APK در Codemagic

این پروژه یک اپ اندرویدی بومی با شناسه `com.iborn.reminder` است.
داده‌ها روی خود گوشی و در SharedPreferences ذخیره می‌شوند؛ ورود و حساب کاربری ندارد.
اعلان‌ها با AlarmManager زمان‌بندی می‌شوند و پس از راه‌اندازی مجدد گوشی دوباره زمان‌بندی می‌شوند.
تم روشن/تیره نیز ذخیره می‌شود.

## ساخت APK
1. فایل ZIP را در GitHub به‌صورت یک مخزن جدید آپلود کنید (محتویات ZIP، نه خود ZIP).
2. در Codemagic وارد شوید و مخزن GitHub را متصل کنید.
3. Codemagic فایل `codemagic.yaml` را شناسایی می‌کند؛ workflow با نام `Reminder Android APK` را اجرا کنید.
4. از بخش Artifacts فایل APK داخل مسیر `app/build/outputs/apk/debug/` را دریافت کنید.
5. APK از نوع debug و امضاشده با کلید debug است و برای نصب و تست روی گوشی مناسب است.

## نکات مهم
- برای اندروید 13 به بالا، اجازه اعلان در اولین اجرا درخواست می‌شود.
- برای زمان‌بندی دقیق در بعضی نسخه‌های اندروید، باید اجازه Alarms & reminders از تنظیمات گوشی فعال شود؛ در غیر این صورت اعلان با زمان‌بندی غیردقیق تنظیم می‌شود.
- فعلاً تاریخ ورودی میلادی است. انتخاب‌گر تاریخ شمسی و ویرایش یادآوری در این نسخه پیاده‌سازی نشده‌اند.
- این نسخه یک پایه قابل ساخت و آزمایش است؛ پیش از انتشار عمومی باید روی چند گوشی تست شود.
